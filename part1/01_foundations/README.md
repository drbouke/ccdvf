# 1. Foundations

Part 1. Building with Claude. The lesson covers 1.1 Models and Behavior.

| # | Program | Concept | Output |
|---|---|---|---|
| 1 | `effort.py` | Effort | The same ticket at low and high effort, with its blocks and output tokens |

Run every program from the `ccdvf` folder, for example:

```

```

The `recorded_runs` folder holds the real output of each program, with its tokens and cost.

# 3. Prompts and Output

Part 1. Building with Claude. The lesson covers 3.1 Prompts and Output.

| # | Program | Concept | Output |
|---|---|---|---|
| 1 | `label_prompts.py` | Output constraints and examples | The replies of each prompt on ten tickets, and how many are exact labels |
| 2 | `structured_ticket.py` | Structured outputs | Three tickets triaged as JSON that always parses |

Run every program from the `ccdvf` folder, for example:

```
python run.py part1/03_prompts_and_output/label_prompts.py
```

The `recorded_runs` folder holds the real output of each program, with its tokens and cost.

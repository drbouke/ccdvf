# 7. Claude Code

Part 2. Shipping with Claude. The lesson covers 7.1 Claude Code Setup.

| # | Program | Concept | Output |
|---|---|---|---|
| 1 | `permissions.py` | Permission rules, deny over allow | A policy read that runs and a tickets read that a deny rule refuses |

The program uses the Claude Agent SDK, which runs the Claude Code engine. Run every program from the `ccdvf` folder, for example:

```
python run.py part2/07_claude_code/permissions.py
```

The `recorded_runs` folder holds the real output of each program.

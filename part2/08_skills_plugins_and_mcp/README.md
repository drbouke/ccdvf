# 8. Skills, Plugins, and MCP

Part 2. Shipping with Claude. The lesson covers 8.1 Skills and Plugins and 8.2 MCP Servers.

| # | Program | Concept | Output |
|---|---|---|---|
| 1 | `orders_client.py` | MCP client and server | The server's tool and resource, one order, and the policy size |
| 2 | `orders_server.py` | MCP server over stdio | A tool and a resource for Acme orders, started by the client |

Run every program from the `ccdvf` folder, for example:

```
python run.py part2/08_skills_plugins_and_mcp/orders_client.py
```

The `recorded_runs` folder holds the real output of each program, with its tokens and cost.

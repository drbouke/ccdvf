# 1.3 Agent Patterns and Frameworks

This lesson manages a long session with context editing and returns typed output through a framework. Run each program from the `ccdvf` folder, for example `python run.py domain1/1.3_agent_patterns/context_clearing.py`.

| Program | Concept | Output |
|---|---|---|
| `context_clearing.py` | Context editing | A 30-order review with old tool results cleared |
| `context_clearing.py --off` | Context editing off | The same review without clearing, for comparison |
| `returns.py` | Pydantic AI, typed output | Return requests decided against the policy as validated `ReturnDecision` objects |

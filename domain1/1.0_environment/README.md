# Development Environment

This lesson builds the environment and follows the API key from a file to a request. Run each program from the `ccdvf` folder, for example `python run.py domain1/1.0_environment/inject_key.py`.

| Program | Concept | Output |
|---|---|---|
| `inject_key.py` | API key injection | The key at each stage, from the `.env` file to the request header |
